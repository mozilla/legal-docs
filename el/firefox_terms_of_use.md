# Όροι χρήσης του Firefox

Ημερομηνία ενεργοποίησης, 16 Σεπτεμβρίου 2026
{: datetime="2026-09-16" }

Ο Firefox είναι δωρεάν λογισμικό περιήγησης ιστού ανοικτού κώδικα, που δημιουργήθηκε από μια κοινότητα χιλιάδων ατόμων από όλο τον κόσμο.

Διαβάστε προσεκτικά αυτούς τους Όρους χρήσης, διότι εξηγούν σημαντικές πληροφορίες σχετικά με τη χρήση του αντιγράφου σας του λογισμικού Firefox. Οι παρόντες Όροι αποτελούν δεσμευτική συμφωνία μεταξύ της Mozilla Corporation («Mozilla») και εσάς. Για λεπτομέρειες σχετικά με τις πρακτικές απορρήτου του Firefox, διαβάστε τη [Δήλωση απορρήτου του Firefox](https://www.mozilla.org/privacy/firefox/#notice).

## Η Mozilla σάς παραχωρεί ορισμένα δικαιώματα και άδειες

Η Mozilla σάς παραχωρεί μια προσωπική, μη αποκλειστική άδεια για την εγκατάσταση και τη χρήση της έκδοσης «Εκτελέσιμου κώδικα» του προγράμματος περιήγησης ιστού Firefox, η οποία είναι η έτοιμη προς εκτέλεση έκδοση του Firefox από εξουσιοδοτημένη πηγή, την οποία μπορείτε να ανοίξετε και να χρησιμοποιήσετε αμέσως.

### Το Firefox είναι λογισμικό ανοικτού κώδικα

Κάνουμε τον πηγαίο κώδικα του Firefox διαθέσιμο σε εσάς βάσει των όρων διαφόρων αδειών ανοικτού κώδικα, συμπεριλαμβανομένης της [Mozilla Public License](https://www.mozilla.org/MPL/). Αυτό σημαίνει ότι μπορείτε να χρησιμοποιείτε, να αντιγράφετε, να τροποποιείτε και να διανέμετε τον Firefox σε άλλους, εφόσον τηρείτε τις άδειες ανοικτού κώδικα και τις [Οδηγίες για τα εμπορικά σήματα της Mozilla](https://www.mozilla.org/foundation/trademarks/policy/). Οι παρόντες Όροι ισχύουν μόνο για την έκδοση Εκτελέσιμου κώδικα του Firefox και όχι για τον πηγαίο κώδικα του Firefox.

Για την αναπαραγωγή ορισμένων τύπων βίντεο, ο Firefox ενδέχεται να πραγματοποιήσει λήψη αρθρωμάτων αποκρυπτογράφησης περιεχομένου από τρίτους, τα οποία ενδέχεται να μην είναι ανοικτού κώδικα.

### Πνευματική ιδιοκτησία της Mozilla

Η Mozilla δεν σας εκχωρεί με τον Firefox οποιοδήποτε δικαίωμα πνευματικής ιδιοκτησίας, το οποίο δεν αναφέρεται ρητά στους παρόντες Όρους. Για παράδειγμα, οι παρόντες Όροι δεν παρέχουν το δικαίωμα χρήσης οποιωνδήποτε δικαιωμάτων copyright, εμπορικών σημάτων ή άλλων διακριτικών χαρακτηριστικών μάρκας της Mozilla ή των χορηγών άδειάς της.

## Αν χρησιμοποιείτε ορισμένες προαιρετικές δυνατότητες ή υπηρεσίες του Firefox, ισχύουν πρόσθετοι όροι

### Ορισμένες υπηρεσίες στον Firefox απαιτούν λογαριασμό Mozilla

Αν θέλετε να χρησιμοποιήσετε ορισμένες υπηρεσίες, όπως τον συγχρονισμό, θα χρειαστείτε έναν λογαριασμό Mozilla. Για να δημιουργήσετε έναν λογαριασμό Mozilla, θα χρειαστεί επίσης να συμφωνήσετε με [Όρους υπηρεσίας](https://www.mozilla.org/about/legal/terms/services/) και τη [Δήλωση απορρήτου για τους λογαριασμούς Mozilla](https://www.mozilla.org/privacy/mozilla-accounts/).

### Άλλες προαιρετικές υπηρεσίες

Για ορισμένες δυνατότητες του Firefox απαιτείται να δηλώσετε ρητά ότι τις επιλέγετε. Για να τις χρησιμοποιήσετε, θα πρέπει να συμφωνήσετε με τους συγκεκριμένους Όρους και τη Δήλωση απορρήτου για κάθε υπηρεσία που χρησιμοποιείτε.

## Η Mozilla μπορεί να ενημερώσει ή να καταγγείλει την παρούσα Σύμβαση

### Η Mozilla μπορεί να ενημερώσει τους παρόντες Όρους

Κατά καιρούς, η Mozilla μπορεί να αποφασίζει να ενημερώνει τους παρόντες Όρους. Θα αναρτούμε τους ενημερωμένους Όρους online. Θα θεωρήσουμε τη συνέχιση της χρήσης του Firefox ως αποδοχή των εν λόγω αλλαγών. Θα δημοσιεύσουμε μια ημερομηνία θέσης σε ισχύ στο επάνω μέρος αυτής της σελίδας για να διευκρινίσουμε πότε κάναμε την πλέον πρόσφατη ενημέρωση.

### Καταγγελία

Αυτοί οι Όροι ισχύουν μέχρι εσείς ή η Mozilla να αποφασίσετε να τους καταγγείλετε. Μπορείτε να επιλέξετε τον τερματισμό τους οποιαδήποτε στιγμή και για οποιαδήποτε αιτία, σταματώντας να κάνετε χρήση του Firefox. Η Mozilla μπορεί να αναστείλει ή να τερματίσει την πρόσβαση οποιουδήποτε στον Firefox ανά πάσα στιγμή και για οποιαδήποτε αιτία, συμπεριλαμβανομένου του ενδεχομένου η Mozilla να αποφασίσει να πάψει να προσφέρει τον Firefox. Αν αποφασίσουμε να αναστείλουμε ή να τερματίσουμε την πρόσβασή σας, θα προσπαθήσουμε να σας ενημερώσουμε στη διεύθυνση email που σχετίζεται με τον λογαριασμό σας ή την επόμενη φορά που θα προσπαθήσετε να αποκτήσετε πρόσβαση στον λογαριασμό σας.
