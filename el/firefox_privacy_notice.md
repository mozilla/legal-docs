# Δήλωση απορρήτου Firefox

Ημερομηνία ενεργοποίησης, 4 Μαΐου 2026
{: datetime="2026-05-04" }

## Στη Mozilla, πιστεύουμε ότι το απόρρητο είναι θεμελιώδους σημασίας για ένα υγιές διαδίκτυο

Αυτός είναι ο λόγος για τον οποίο δημιουργούμε τον Firefox και όλα τα προϊόντα μας, για να σας παρέχουμε μεγαλύτερο έλεγχο όσον αφορά τις πληροφορίες που κοινοποιείτε στο διαδίκτυο και τις πληροφορίες που κοινοποιείτε σε εμάς. Στην παρούσα Δήλωση Απορρήτου, εξηγούμε ποια δεδομένα επεξεργαζόμαστε, πώς τα επεξεργαζόμαστε και για ποιους σκοπούς. Στη συνέχεια, εξηγούμε πώς μπορείτε να ασκήσετε επιλογές σχετικά με τον τρόπο με τον οποίο επεξεργαζόμαστε τα δεδομένα σας.

## Πώς χρησιμοποιούνται τα δεδομένα σας;

### Για να σας παρέχουμε το πρόγραμμα περιήγησης Firefox

Η Mozilla συλλέγει [ορισμένα δεδομένα](#bookmark-how-we-use-data), όπως τεχνικά δεδομένα και δεδομένα ρυθμίσεων, για να παρέχει τη βασική λειτουργικότητα του προγράμματος περιήγησης Firefox και των σχετικών υπηρεσιών, να διακρίνει τη συσκευή σας από άλλες, να απομνημονεύει και να τηρεί τις ρυθμίσεις σας και να σας παρέχει προεπιλεγμένες δυνατότητες, όπως τη [Νέα καρτέλα](https://support.mozilla.org/kb/about-new-tab-page), την [επεξεργασία αρχείων PDF](https://support.mozilla.org/kb/view-pdf-files-firefox-or-choose-another-viewer), τη [διαχείριση κωδικών πρόσβασης](https://support.mozilla.org/kb/manage-your-logins-firefox-password-manager) και την [Ολική προστασία cookie](https://support.mozilla.org/kb/introducing-total-cookie-protection-standard-mode). Μπορείτε να προσαρμόσετε περαιτέρω την εμπειρία σας στον Firefox ρυθμίζοντας τα [στοιχεία ελέγχου, τα κουμπιά και τις γραμμές εργαλείων](https://support.mozilla.org/kb/customize-firefox-controls-buttons-and-toolbars) και προσθέτοντας [δυνατότητες με πρόσθετα](https://support.mozilla.org/kb/find-and-install-add-ons-add-features-to-firefox).

Ορισμένες δυνατότητες του Firefox, όπως η αυτόματη [μετάφραση](https://support.mozilla.org/kb/website-translation) ιστοσελίδων και [οι προτάσεις «εναλλακτικού κειμένου» όταν κάνετε αποστολή εικόνων στα αρχεία σας PDF](https://support.mozilla.org/kb/pdf-alt-text), λειτουργούν με τεχνητή νοημοσύνη (ΤΝ) που βασίζεται σε μικρά γλωσσικά μοντέλα που λαμβάνονται στη συσκευή σας. Αυτά λειτουργούν τοπικά — το περιεχόμενο των ιστοσελίδων, τα αρχεία PDF, οι εικόνες και οι διευθύνσεις URL των καρτελών παραμένουν στη συσκευή σας και δεν αποστέλλονται στους διακομιστές της Mozilla ούτε χρησιμοποιούνται για σκοπούς εκπαίδευσης χωρίς τη ρητή συγκατάθεσή σας. Λάβετε υπόψη ότι άλλες δυνατότητες του Firefox ενδέχεται να ενσωματώνουν μοντέλα τεχνητής νοημοσύνης τρίτων, όπως περιγράφεται λεπτομερέστερα στην παρούσα Δήλωση. Μάθετε περισσότερα, συμπεριλαμβανομένου του τρόπου [ελέγχου των δυνατοτήτων και των μοντέλων που βασίζονται σε ΤΝ](https://support.mozilla.org/kb/firefox-ai-controls) από τις ρυθμίσεις σας.

Αν επιλέξετε να χρησιμοποιήσετε τη δυνατότητα Έξυπνο παράθυρο, η χρήση εκ μέρους σας της δυνατότητας διέπεται από τη Δήλωση Απορρήτου του [Έξυπνου παραθύρου](https://www.mozilla.org/privacy/smart-window/), η οποία εξηγεί πώς γίνεται η επεξεργασία των δεδομένων σε σχέση με το Έξυπνο παράθυρο.

### Για να προσαρμόσετε τον Firefox στις ανάγκες σας

Ο Firefox επεξεργάζεται διάφορα δεδομένα προσωπικού χαρακτήρα με τρόπο που δεν τα μεταφέρει εκτός της συσκευής σας, όπως το ιστορικό περιήγησης, τα δεδομένα φορμών ιστοσελίδων, τα προσωρινά αρχεία Internet και τα cookie. Αυτό σημαίνει ότι τα δεδομένα παραμένουν στη συσκευή σας και δεν στέλνονται στους διακομιστές της Mozilla, εκτός αν αναφέρεται διαφορετικά στην παρούσα Δήλωση. Αν επιλέξετε να το επιτρέψετε, η ακριβής τοποθεσία σας μπορεί επίσης να υποβληθεί σε επεξεργασία για λειτουργίες που σχετίζονται με την τοποθεσία σε ιστότοπους όπως οι Χάρτες Google. Η πρόσβαση σε αυτά τα δεδομένα από τη συσκευή σας γίνεται μόνο από τον/τους ιστότοπο/ους για τον/τους οποίο/ους επιλέγετε να τα ενεργοποιήσετε — δεν στέλνονται στους διακομιστές της Mozilla.

Αν ενεργοποιήσετε τη δυνατότητα Ανακίνηση για σύνοψη σε μια συμβατή συσκευή με υποστηριζόμενο λειτουργικό σύστημα που επιτρέπει τη χρήση τεχνητής νοημοσύνης στη συσκευή, οι συνόψεις που ζητάτε θα δημιουργούνται τοπικά στη συσκευή σας. Διαφορετικά, όταν ζητάτε μια σύνοψη, το περιεχόμενο της σελίδας σας θα στέλνεται σε έναν διακομιστή της Mozilla για επεξεργασία και θα επιστρέφεται στη συσκευή σας. Η Mozilla δεν αποθηκεύει αυτό το περιεχόμενο ούτε τις συνόψεις που προκύπτουν. Μάθετε περισσότερα για τη λειτουργία Ανακίνηση για σύνοψη σε [iOS](https://blog.mozilla.org/en/firefox/shake-to-summarize/) και [Android](https://support.mozilla.org/kb/summarize-pages-android).

*Περισσότερες λεπτομέρειες, συμπεριλαμβανομένου του τρόπου προσαρμογής των ρυθμίσεων δεδομένων σας:* Τα δεδομένα που υποβάλλονται σε επεξεργασία στη συσκευή σας παραμένουν υπό τον έλεγχό σας. Μπορείτε να [διαχειρίζεστε τα δεδομένα περιήγησής σας](https://support.mozilla.org/kb/delete-browsing-search-download-history-firefox) και τις [ρυθμίσεις τοπικού αποθηκευτικού χώρου](https://support.mozilla.org/kb/storage) σας ή να ενημερώνετε τα [δικαιώματα τοποθεσίας σας](https://support.mozilla.org/kb/does-firefox-share-my-location-websites) ανά πάσα στιγμή.

### Για να σας παρέχουμε το Firefox VPN

Αν έχετε πραγματοποιήσει είσοδο σε έναν λογαριασμό Mozilla, μπορείτε να ενεργοποιήσετε μια δυνατότητα του Firefox για να αποκρύψετε τη διεύθυνση IP σας μέσω ενός διακομιστή μεσολάβησης («VPN»). Όταν η δυνατότητα αυτή είναι ενεργοποιημένη, μεσολαβεί ώστε η κίνηση δικτύου του Firefox να δρομολογείται μέσω ενός ενδιάμεσου, ώστε να μην μπορεί ο πάροχος δικτύου σας να βλέπει σε ποιους διακομιστές συνδέεστε και να αποκρύπτεται η διεύθυνση IP σας από τους ιστότοπους που επισκέπτεστε. Δεν μεσολαβεί για την κίνηση από άλλες εφαρμογές στη συσκευή, ούτε καθιστά, από μόνη της, την περιήγησή σας σε ιστότοπους απολύτως ανώνυμη. Η χρήση VPN μπορεί να επηρεάσει την εμπειρία περιήγησής σας, μεταξύ άλλων με την προβολή περιεχομένου που δεν αφορά συγκεκριμένα την περιοχή σας.

Για να παρέχουμε τη δυνατότητα VPN, χρησιμοποιούμε έναν διακομιστή μεσολάβησης που λειτουργεί για λογαριασμό μας. Ο διακομιστής μεσολάβησης δεν έχει πρόσβαση στο περιεχόμενο των ιστοσελίδων ή σε άλλες ευαίσθητες πληροφορίες, όπως μηνύματα ή κωδικούς πρόσβασης, ενώ δεν συλλέγει δεδομένα σχετικά με τους ιστότοπους που επισκέπτεστε ή σχετικά με το περιεχόμενο αυτών των ιστότοπων. Επεξεργαζόμαστε περιορισμένα τεχνικά δεδομένα (όπως την έκδοση του προγράμματος-πελάτη, την κατάσταση σύνδεσης και τον τύπο συσκευής/το λειτουργικό σύστημα) για την παροχή, τη συντήρηση και τη διασφάλιση της απόδοσης και της σταθερότητας της υπηρεσίας, καθώς και δεδομένα αλληλεπίδρασης για να κατανοήσουμε τη χρήση της δυνατότητας και να συμβάλουμε στη δρομολόγηση βελτιώσεων.

### Για την παροχή και τη βελτίωση της λειτουργικότητας και των προτάσεων αναζήτησης

Καθώς πληκτρολογείτε ένα ερώτημα αναζήτησης στον Firefox, ο Firefox προτείνει [προτάσεις αναζήτησης](https://support.mozilla.org/kb/search-suggestions-firefox) για να σας παρέχει ταχύτερη και πιο άμεση πρόσβαση σε αυτό που αναζητάτε. Ορισμένες από τις προτάσεις αναζήτησης προέρχονται από τον πάροχο αναζήτησης της επιλογής σας («Προτάσεις αναζήτησης»). Άλλες προέρχονται από τον Firefox και βασίζονται σε πληροφορίες που αποθηκεύονται στην τοπική συσκευή σας (συμπεριλαμβανομένων των πρόσφατων όρων αναζήτησης, των ανοιχτών καρτελών και των διευθύνσεων URL που έχετε επισκεφτεί στο παρελθόν) ή σε περιεχόμενο από τη Mozilla και τους συνεργάτες της Mozilla, συμπεριλαμβανομένων χορηγών έναντι αμοιβής και πηγών στο Internet, όπως η Wikipedia («Προτάσεις Firefox»).

Από προεπιλογή, ο Firefox εμφανίζει Προτάσεις αναζήτησης. Τα αιτήματα για προτάσεις — συμπεριλαμβανομένου του ερωτήματός σας αναζήτησης σε πραγματικό χρόνο και των τεχνικών δεδομένων σας — στέλνονται απευθείας στον πάροχο αναζήτησης της επιλογής σας καθώς πληκτρολογείτε και υποβάλλονται σε επεξεργασία σύμφωνα με τη δήλωση απορρήτου του παρόχου αναζήτησης της επιλογής σας ([ακολουθεί σύνδεσμος](#bookmark-search-pns)). Μπορείτε να απενεργοποιήσετε τις Προτάσεις αναζήτησης ή να αλλάξετε τον προεπιλεγμένο πάροχο αναζήτησης ανά πάσα στιγμή, όπως περιγράφεται σε αυτή τη σελίδα της [Υποστήριξης Firefox](https://support.mozilla.org/kb/firefox-suggest).

Οι χρήστες στις Η.Π.Α. και σε ορισμένες άλλες περιοχές θα λαμβάνουν επίσης Προτάσεις Firefox. Μπορείτε να τις απενεργοποιήσετε εντελώς ή απλώς να απενεργοποιήσετε τις χορηγούμενες Προτάσεις Firefox, στις ρυθμίσεις του προγράμματος περιήγησής σας.

Στις Η.Π.Α., ο Firefox ανακτά προτάσεις από τους διακομιστές της Mozilla καθώς πληκτρολογείτε το ερώτημά σας. Χρησιμοποιούμε μια τεχνολογία προστασίας του απορρήτου που ονομάζεται [OHTTP](https://blog.mozilla.org/en/products/firefox/partnership-ohttp-prio/), η οποία συνδυάζει την κρυπτογράφηση και έναν διακομιστή μεσολάβησης για να αποκρύπτει τη διεύθυνση IP σας και άλλα στοιχεία ταυτοποίησης. Το ερώτημα αναζήτησης σε πραγματικό χρόνο, μαζί με τα τεχνικά δεδομένα, τα δεδομένα αλληλεπίδρασης και τα δεδομένα τοποθεσίας που προέρχονται από τη διεύθυνση IP, διαβιβάζονται μέσω αυτού του διακομιστή μεσολάβησης OHTTP από προεπιλογή, προτού σταλούν στη Mozilla. Αυτό βοηθά στην αποτροπή της σύνδεσης του συγκεκριμένου ερωτήματός σας με εσάς από οποιονδήποτε (συμπεριλαμβανομένης της Mozilla) ή του συνδυασμού του με μη σχετικές πληροφορίες σχετικά με τη δραστηριότητα περιήγησής σας. Η Mozilla επεξεργάζεται αυτά τα δεδομένα για να σας παρέχει σχετικές προτάσεις, να κατανοεί πόσο χρήσιμες είναι οι προτάσεις για εσάς και να βελτιώνει την υπηρεσία. Σε ορισμένες περιπτώσεις, οι συνεργάτες της Mozilla θα λαμβάνουν δεδομένα αναζήτησης και αλληλεπίδρασης χωρίς στοιχεία ταυτοποίησης, προκειμένου να παρέχουν σχετικές προτάσεις και να μετρούν την ενασχόληση των χρηστών με το προτεινόμενο περιεχόμενο.

Ορισμένοι χρήστες — συμπεριλαμβανομένων των χρηστών σε ορισμένες περιοχές εκτός των Η.Π.Α. και των χρηστών που εδρεύουν στις Η.Π.Α. και έχουν καταργήσει την επιλογή «Λήψη προτάσεων από τη Mozilla κατά την πληκτρολόγηση» στις ρυθμίσεις τους — θα λαμβάνουν, στη θέση τους, αποτελέσματα που υποβάλλονται σε επεξεργασία τοπικά όταν χρησιμοποιούν τη δυνατότητα «Προτάσεις Firefox». Για αυτούς τους χρήστες, οι προτάσεις θα παρέχονται τοπικά, χρησιμοποιώντας πληροφορίες που αποθηκεύονται στη συσκευή σας, στο αντίγραφό σας του Firefox. Τα δεδομένα των κλικ και των αλληλεπιδράσεών σας, χωρίς στοιχεία ταυτοποίησης, για συγκεκριμένες λέξεις-κλειδιά αναζήτησης (αλλά όχι για το ερώτημα αναζήτησής σας) στέλνονται στη Mozilla μέσω του πρωτοκόλλου OHTTP για να αποκρύπτονται η διεύθυνση IP και άλλα στοιχεία ταυτοποίησής σας. Όσον αφορά τις χορηγούμενες προτάσεις, οι συνεργάτες μας ενδέχεται να λαμβάνουν συγκεντρωτικές πληροφορίες σχετικά με το ποιες από τις προτάσεις τους εμφανίζονται και λαμβάνουν κλικ, αλλά όχι σχετικά με το ποιοι χρήστες είδαν τις προτάσεις ή ποιες λέξεις-κλειδιά οδήγησαν στην προβολή αυτών των προτάσεων. (Αν οι Προτάσεις Firefox δεν είναι διαθέσιμες στην περιοχή σας, θα λαμβάνετε μόνο Προτάσεις αναζήτησης).

### Για την προβολή σχετικού περιεχομένου και διαφημίσεων στη Νέα καρτέλα του Firefox

Ο Firefox εμφανίζει περιεχόμενο στη Νέα καρτέλα, μαζί με διαφημίσεις για την υποστήριξη της ανάπτυξής του. Μπορείτε να απενεργοποιήσετε την εμφάνισή τους ανά πάσα στιγμή από τις ρυθμίσεις του προγράμματος περιήγησής σας.

Χρησιμοποιούμε τεχνικά δεδομένα, προτιμήσεις γλώσσας και δεδομένα τοποθεσίας που προέρχονται από τη διεύθυνση IP για να παρέχουμε αυτό το περιεχόμενο στη σωστή μορφή (π.χ. για κινητά έναντι σταθερών υπολογιστών), στη σωστή γλώσσα και για τη σχετική τοποθεσία. Η Mozilla συλλέγει τεχνικά δεδομένα και δεδομένα αλληλεπίδρασης, όπως τη θέση, το μέγεθος, τις προβολές και τα κλικ σε περιεχόμενο ή διαφημίσεις στη Νέα καρτέλα, για να κατανοήσει τον τρόπο με τον οποίο οι χρήστες αλληλεπιδρούν με το περιεχόμενό μας και για να εξατομικεύσει το μελλοντικό περιεχόμενο, συμπεριλαμβανομένου του χορηγούμενου περιεχομένου. Αυτά τα δεδομένα ενδέχεται να κοινοποιούνται στους διαφημιστικούς συνεργάτες μας σε συγκεντρωτική βάση ή/και χωρίς δεδομένα ταυτοποίησης.

Σε ορισμένες περιοχές, χρησιμοποιούμε αυτά τα δεδομένα για να δημιουργήσουμε μοντέλα και να ομαδοποιήσουμε τους χρήστες με βάση κοινά χαρακτηριστικά. Αυτές οι ομαδοποιήσεις μας βοηθούν να κατανοήσουμε τον τρόπο με τον οποίο οι χρήστες αλληλεπιδρούν με το περιεχόμενό μας και να εξατομικεύουμε το μελλοντικό περιεχόμενο, συμπεριλαμβανομένου του χορηγούμενου περιεχομένου. Χρησιμοποιούμε την επεξεργασία στη συσκευή και το πρωτόκολλο OHTTP για να αποφεύγουμε τη γνωστοποίηση των χαρακτηριστικών οποιουδήποτε συγκεκριμένου χρήστη στη Mozilla. [Μάθετε περισσότερα](https://support.mozilla.org/kb/firefox-new-tab-personalization).

Συνεργαζόμαστε επίσης με παρόχους διαφημίσεων για την παροχή σχετικού χορηγούμενου περιεχομένου χρησιμοποιώντας τεχνολογίες προγραμματικής διαφήμισης. Για την υποστήριξη αυτής της διαδικασίας, ενδέχεται να κοινοποιούμε περιορισμένες, μη ταυτοποιήσιμες πληροφορίες — όπως τον τύπο συσκευής, τις πληροφορίες τοποθεσίας που προέρχονται από τη διεύθυνση IP και την κατηγορία του περιεχομένου που προβάλλεται — για να βοηθήσουμε στον προσδιορισμό των διαφημίσεων που θα εμφανίζονται. Δεν κοινοποιούμε πληροφορίες που σας ταυτοποιούν. Μπορείτε να απενεργοποιήσετε το χορηγούμενο περιεχόμενο στις ρυθμίσεις σας Νέας καρτέλας ανά πάσα στιγμή.

Σε ορισμένες περιπτώσεις, όταν οι διαφημίσεις είναι ενεργοποιημένες στη Νέα καρτέλα, ενδέχεται επίσης να υποβάλλονται σε επεξεργασία τοπικά στη συσκευή σας πρόσθετα δεδομένα περιήγησης και αλληλεπίδρασης (συμπεριλαμβανομένων των αλληλεπιδράσεων με τους διαφημιζόμενούς μας) για τη μέτρηση της αποτελεσματικότητας αυτών των διαφημίσεων. Η δυνατότητα [συντομεύσεων](https://support.mozilla.org/kb/about-new-tab-page#w_shortcuts) χρησιμοποιεί επίσης δεδομένα περιήγησης τοπικά στη συσκευή σας για την επιλογή των κορυφαίων συντομεύσεων, ορισμένες από τις οποίες μπορεί να είναι χορηγούμενες. Τυχόν τέτοια δεδομένα θα κοινοποιούνται μόνο στη Mozilla ή/και στους συνεργάτες μας διαφήμισης μέσω των τεχνολογιών μας για την προστασία του απορρήτου σε συγκεντρωτική βάση ή/και χωρίς δεδομένα ταυτοποίησης.

Όταν ένας χρήστης επισκέπτεται έναν ιστότοπο τρίτου κάνοντας κλικ σε μια διαφήμιση ή σε έναν σύνδεσμο στον Firefox, ο εν λόγω ιστότοπος ενδέχεται να χρησιμοποιεί cookie και άλλα API ιστού που είναι διαθέσιμα σε κάθε ιστότοπο για τη συλλογή δεδομένων, σύμφωνα με τις δηλώσεις απορρήτου ή/και τις δηλώσεις για τα cookie του εν λόγω ιστότοπου.

Μπορείτε να απενεργοποιήσετε ή να προσαρμόσετε οποιαδήποτε από αυτές τις δυνατότητες της Νέας καρτέλας, καθώς και τη σχετική επεξεργασία δεδομένων, στις ρυθμίσεις του προγράμματος περιήγησής σας ([σε υπολογιστή](https://support.mozilla.org/kb/customize-your-new-tab-page), [Android](https://support.mozilla.org/kb/customize-firefox-home-screen), [iOS](https://support.mozilla.org/kb/customize-firefox-home-ios)). Μπορείτε επίσης να [απενεργοποιήσετε το χορηγούμενο περιεχόμενο](https://support.mozilla.org/kb/sponsor-privacy), ενώ συνεχίζετε να χρησιμοποιείτε τις υπόλοιπες δυνατότητες.

### Για την παροχή λογαριασμών Mozilla

Αν επιλέξετε να ενεργοποιήσετε ένα chatbot στην πλαϊνή γραμμή ή/και μέσω μιας συντόμευσης, η Mozilla δεν έχει πρόσβαση στις συνομιλίες σας ή στο υποκείμενο περιεχόμενο που καταχωρείτε στο επιλεγμένο chatbot. Συλλέγουμε τεχνικά δεδομένα και δεδομένα αλληλεπίδρασης σχετικά με τον τρόπο χρήσης αυτής της δυνατότητας, για να συμβάλουμε στη βελτίωση του Firefox, όπως πόσο συχνά επιλέγεται κάθε τρίτος πάροχος chatbot, πόσο συχνά χρησιμοποιούνται οι προτεινόμενες προτροπές και το μήκος του επιλεγμένου κειμένου.

Μπορείτε να εγκαταστήσετε πρόσθετα από το [addons.mozilla.org](https://addons.mozilla.org) («AMO») ή από τη Διαχείριση προσθέτων του Firefox, στην οποία μπορείτε να αποκτήσετε πρόσβαση από το κουμπί μενού του Firefox στη γραμμή εργαλείων. Αν επιλέξετε να εγκαταστήσετε πρόσθετα, ο Firefox θα υποβάλει σε επεξεργασία τεχνικά δεδομένα, δεδομένα τοποθεσίας που προέρχονται από τη διεύθυνση IP και δεδομένα ρυθμίσεων, ενώ θα συνδέεται κατά τακτά διαστήματα με τους διακομιστές της Mozilla για να εγκαθιστά και να εφαρμόζει τις σωστές ενημερώσεις στα πρόσθετά σας. Συλλέγουμε επίσης τεχνικά δεδομένα και δεδομένα αλληλεπίδρασης σχετικά με τη χρήση των προσθέτων, για να συμβάλουμε στη βελτίωση του Firefox.

Όταν επισκέπτεστε τον ιστότοπο [AMO](https://addons.mozilla.org/firefox/), η Mozilla συλλέγει τεχνικά δεδομένα και δεδομένα αλληλεπίδρασης σχετικά με τη χρήση του ιστότοπου από εσάς, σύμφωνα με τη δήλωση [ιστότοπων, επικοινωνιών και cookie](https://www.mozilla.org/privacy/websites/) της Mozilla.

*Περισσότερες λεπτομέρειες, συμπεριλαμβανομένου του τρόπου προσαρμογής των ρυθμίσεων δεδομένων σας:* Μάθετε [πώς να καταργείτε ή να ενεργοποιείτε πρόσθετα](https://support.mozilla.org/kb/disable-or-remove-add-ons). Μπορείτε επίσης να διαβάσετε τη [Δήλωση απορρήτου](https://www.mozilla.org/privacy/websites/) για τον [ιστότοπο των προσθέτων](https://addons.mozilla.org/firefox/).

### Για τη διατήρηση και τη βελτίωση των δυνατοτήτων, της απόδοσης και της σταθερότητας

Η Mozilla διεξάγει [μελέτες](https://support.mozilla.org/kb/shield) στο πλαίσιο του Firefox και διαθέτει ορισμένες [πειραματικές δυνατότητες](https://support.mozilla.org/kb/firefox-labs-explore-experimental-features-firefox) μέσω των Firefox Labs για να δοκιμάζει διάφορες δυνατότητες και ιδέες πριν αυτές διατεθούν σε όλους τους χρήστες του Firefox ή ενσωματωθούν στις βασικές δυνατότητες του Firefox. Έτσι, μπορούμε να λαμβάνουμε πιο τεκμηριωμένες αποφάσεις σχετικά με το τι θέλουν και τι χρειάζονται οι χρήστες μας. Αυτή η έρευνα χρησιμοποιεί τεχνικά δεδομένα, δεδομένα απόδοσης συστήματος, δεδομένα τοποθεσίας που προέρχονται από τη διεύθυνση IP, δεδομένα ρυθμίσεων και δεδομένα αλληλεπίδρασης.

Πρέπει επίσης να επεξεργαζόμαστε δεδομένα για να διατηρούμε τον Firefox λειτουργικό, να βελτιώνουμε τις δυνατότητες και την απόδοση και να εντοπίζουμε, να επιλύουμε και να διαγιγνώσκουμε προβλήματα. Για τον σκοπό αυτό, χρησιμοποιούμε τεχνικά δεδομένα, δεδομένα τοποθεσίας που προέρχονται από τη διεύθυνση IP και δεδομένα ρυθμίσεων, καθώς και δεδομένα αλληλεπίδρασης και απόδοσης του συστήματος (όπως τον αριθμό των ανοιχτών καρτελών, τη χρήση μνήμης ή το αποτέλεσμα αυτοματοποιημένων διαδικασιών, όπως οι ενημερώσεις). Στις σπάνιες περιπτώσεις όπου οι απαιτούμενες πληροφορίες περιλαμβάνουν επίσης περιορισμένα δεδομένα περιήγησης (π.χ. σχολιασμούς domain ανωτάτου επιπέδου για την παρακολούθηση της απόδοσης φόρτωσης σελίδων), αυτά θα διαβιβάζονται μέσω του πρωτοκόλλου OHTTP. Αυτό βοηθά στο να μην επιτρέπεται στη Mozilla να συσχετίσει εσάς ή τη συσκευή σας με τα δεδομένα που συλλέγονται για αυτό τον σκοπό.

Σε υπολογιστές και συσκευές Android, αν ο Firefox αντιμετωπίσει ένα μη αναμενόμενο πρόβλημα, η [Αναφορά καταρρεύσεων Mozilla](https://support.mozilla.org/kb/mozillacrashreporter) θα σας ρωτήσει επίσης αν επιθυμείτε να μας στείλετε πρόσθετες πληροφορίες, οι οποίες ενδέχεται να περιλαμβάνουν ιστότοπους που ήταν ανοιχτοί τη στιγμή του σφάλματος, και άλλα δεδομένα περιήγησης. Σε υπολογιστή και Android, αν επιλέξετε να μας στέλνετε αυτόματα αναφορές σφαλμάτων, συλλέγουμε αυτές τις πληροφορίες χωρίς να σας ρωτάμε κάθε φορά. Στο iOS, οι αναφορές σφαλμάτων περιέχουν λιγότερες πληροφορίες και μας αποστέλλονται αυτόματα από προεπιλογή. Μπορείτε να αλλάξετε τις ρυθμίσεις σας ανά πάσα στιγμή.

*Περισσότερες λεπτομέρειες, συμπεριλαμβανομένου του τρόπου προσαρμογής των ρυθμίσεων δεδομένων σας:* Μπορείτε να [μάθετε περισσότερα](https://support.mozilla.org/kb/shield) σχετικά με τις μελέτες στις οποίες συμμετέχετε και να εξαιρεθείτε από όλες τις μελέτες (ή από μια συγκεκριμένη μελέτη) ανά πάσα στιγμή, καθώς και να επιλέξετε να συμμετέχετε σε πειραματικές δυνατότητες μέσω των [Firefox Labs](https://support.mozilla.org/kb/firefox-labs-explore-experimental-features-firefox). Μπορείτε επίσης να [μάθετε περισσότερα](https://support.mozilla.org/kb/technical-and-interaction-data) σχετικά με τα τεχνικά δεδομένα και τα δεδομένα αλληλεπίδρασης που επεξεργαζόμαστε, συμπεριλαμβανομένου του τρόπου απενεργοποίησής τους.

### Για τη βελτίωση της ασφάλειας

Επειδή η διατήρηση της τελευταίας έκδοσης του Firefox συμβάλλει στην προστασία σας από τρωτά σημεία, οι εκδόσεις του Firefox για υπολογιστές συνδέονται τακτικά με τους διακομιστές της Mozilla (ή με άλλη υπηρεσία που χρησιμοποιήσατε για την εγκατάσταση του Firefox) για να ελέγχουν για ενημερώσεις λογισμικού. Η διαχείριση των ενημερώσεων για τις εκδόσεις του Firefox για Android και iOS γίνεται από το Play Store της Google και το App Store της Apple, αντίστοιχα.

Επεξεργαζόμαστε επίσης τεχνικά δεδομένα και δεδομένα ρυθμίσεων για προστασία από κακόβουλα πρόσθετα.
Εκτός από αυτές τις τυπικές διαδικασίες, χρησιμοποιούμε την [Υπηρεσία ασφαλούς περιήγησης της Google](https://support.mozilla.org/kb/how-does-phishing-and-malware-protection-work) για να σας προστατεύουμε από κακόβουλες λήψεις και επιθέσεις ηλεκτρονικού ψαρέματος και για να επικυρώνουμε τις ιστοσελίδες και τα τεχνικά δεδομένα με τις [Αρχές πιστοποίησης](https://support.mozilla.org/kb/secure-website-certificate). Στο πλαίσιο των προσπαθειών μας για τη βελτίωση του απορρήτου και της ασφάλειας για όλους τους χρήστες του Internet, συλλέγουμε τεχνικά δεδομένα μέσω του OHTTP, για να κατανοούμε καλύτερα, να αποτρέπουμε την καταγραφή αποτυπώματος και να προστατευόμαστε από αυτήν.

Για [ορισμένους χρήστες του Firefox](https://support.mozilla.org/kb/firefox-dns-over-https), ο Firefox δρομολογεί τα αιτήματα DNS σε μια υπηρεσία επίλυσης ονομάτων που έχει συμφωνήσει με τα [αυστηρά πρότυπα απορρήτου της Mozilla για τις υπηρεσίες επίλυσης ονομάτων](https://wiki.mozilla.org/Security/DOH-resolver-policy). Έτσι παρέχεται πρόσθετη προστασία από διαρροές δεδομένων προσωπικού χαρακτήρα σε τοπικά δίκτυα, καθώς και από ορισμένες επιθέσεις ασφαλείας DNS. Τα αρχεία καταγραφής συστήματος των αιτημάτων σας για DNS διαγράφονται από την υπηρεσία εντός 24 ωρών και χρησιμοποιούνται μόνο για τον σκοπό της επίλυσης DNS. [Μάθετε περισσότερα](https://support.mozilla.org/kb/firefox-dns-over-https#w_switching-providers) για το DNS μέσω HTTPS.

*Περισσότερες λεπτομέρειες, συμπεριλαμβανομένου του τρόπου προσαρμογής των ρυθμίσεων δεδομένων σας:* [Λίστα αποκλεισμού αναβαθμίσεων και προσθέτων](https://support.mozilla.org/kb/how-stop-firefox-making-automatic-connections), [Υπηρεσία ασφαλούς περιήγησης της Google](https://support.mozilla.org/kb/how-does-phishing-and-malware-protection-work), [OHTTP](https://blog.mozilla.org/en/products/firefox/partnership-ohttp-prio/).

### Για κατανόηση της χρήσης του Firefox

Επεξεργαζόμαστε [δεδομένα](#bookmark-understand-usage) για να κατανοήσουμε καλύτερα τον τρόπο με τον οποίο αλληλεπιδράτε με τις υπηρεσίες μας, όπως πόσο συχνά χρησιμοποιείτε τον Firefox, την προτίμηση γλώσσας σας, πόσο συχνά χρησιμοποιείτε τα εργαλεία αναζήτησης ή αλληλεπιδράτε με τις προτάσεις αναζήτησης, πόσο γρήγορα φορτώνουν οι σελίδες για εσάς και πόσες διαφημίσεις ή [CAPTCHA](https://en.wikipedia.org/wiki/CAPTCHA) βλέπετε. Έτσι μπορούμε να μετράμε τον τρόπο με τον οποίο οι χρήστες αποκτούν πρόσβαση στις υπηρεσίες μας και τις χρησιμοποιούν, γεγονός που συμβάλλει στη βελτίωση των δραστηριοτήτων μας και της λειτουργικότητας του Firefox.

*Περισσότερες λεπτομέρειες, συμπεριλαμβανομένου του τρόπου προσαρμογής των ρυθμίσεων δεδομένων σας:* Μπορείτε να ενημερώσετε τις ρυθμίσεις συλλογής δεδομένων σας για [υπολογιστές](https://support.mozilla.org/kb/share-data-mozilla-help-improve-firefox) και [κινητές συσκευές](https://support.mozilla.org/kb/mobile-manage-firefox-data-collection-and-privacy) ανά πάσα στιγμή. Λάβετε υπόψη ότι η κατάργηση της επιλογής «Να επιτρέπεται στον Firefox η αποστολή τεχνικών δεδομένων και αλληλεπίδρασης στη Mozilla» δεν θα επηρεάσει το [Ping ημερήσιας χρήσης](https://support.mozilla.org/kb/usage-ping-settings). Αυτό το Ping ημερήσιας χρήσης μας παρέχει αποκλειστικά πληροφορίες χωρίς δεδομένα ταυτοποίησης ότι ένας χρήστης χρησιμοποιεί τον Firefox. Δεν συνδέεται με άλλα δεδομένα που αφορούν εσάς και μπορείτε να επιλέξετε τη μη συμμετοχή σας στις ρυθμίσεις.

### Για την προώθηση των υπηρεσιών μας

Όταν μας επιτρέπετε να το πράξουμε, ο Firefox στέλνει στη Mozilla δεδομένα σχετικά με το domain του ιστότοπου ή τη συγκεκριμένη διαφημιστική εκστρατεία (εφόσον υπάρχει) που σας παρέπεμψε στη σελίδα λήψης μας, για να μας βοηθήσει να κατανοήσουμε και να βελτιώσουμε τις προσπάθειές μας στον τομέα του μάρκετινγκ. Ο Firefox κοινοποιεί επίσης πληροφορίες στους συνεργάτες μας μάρκετινγκ για τη μέτρηση και τη βελτίωση αυτών των εκστρατειών. Οι συγκεκριμένες πληροφορίες που κοινοποιούνται διαφέρουν (ανάλογα με τον τρόπο με τον οποίο ανακαλύψατε τον Firefox και το λειτουργικό σας σύστημα), αλλά γενικά περιλαμβάνουν τον τρόπο με τον οποίο παραπεμφθήκατε στη σελίδα λήψης μας και το αν χρησιμοποιείτε ή όχι ενεργά τον Firefox. Όταν ο Firefox είναι προεγκατεστημένος στη συσκευή σας, τα τεχνικά δεδομένα και τα δεδομένα αλληλεπίδρασης (ο τύπος της συσκευής σας και αν χρησιμοποιείται ή όχι ο Firefox) θα στέλνονται στους συνεργάτες μας στον τομέα του μάρκετινγκ και θα κοινοποιούνται στη Mozilla.

*Περισσότερες λεπτομέρειες, συμπεριλαμβανομένου του τρόπου προσαρμογής των ρυθμίσεων δεδομένων σας:* Μάθετε περισσότερα σχετικά με τα [Δεδομένα μέτρησης εκστρατειών που](https://support.mozilla.org/kb/desktop-attribution-privacy) συλλέγονται και κοινοποιούνται και πώς να εξαιρεθείτε. Ο Firefox δεν κοινοποιεί πληροφορίες όπως το ιστορικό περιήγησής σας, τα ερωτήματα αναζήτησης ή τους αποθηκευμένους κωδικούς πρόσβασής σας σε συνεργάτες τεχνολογίας μάρκετινγκ. Η Mozilla συλλέγει μόνο τα δεδομένα που είναι απαραίτητα για τη μέτρηση και τη βελτίωση των εκστρατειών μας μάρκετινγκ.

### Για την ψευδωνυμοποίηση, την αφαίρεση δεδομένων ταυτοποίησης, τη συγκέντρωση ή την ανωνυμοποίηση δεδομένων

Στο πλαίσιο των δραστηριοτήτων που περιγράφονται παραπάνω, όπως η κατανόηση της χρήσης του Firefox και η μέτρηση των αποτελεσμάτων των ενεργειών μάρκετινγκ, ενδέχεται να δημιουργούμε ψευδωνυμοποιημένα, μη ταυτοποιήσιμα, συγκεντρωτικά ή ανωνυμοποιημένα δεδομένα. Χρησιμοποιούμε τεχνολογία που είναι κατάλληλη για τις εκάστοτε περιστάσεις, όπως την αφαίρεση αναγνωριστικών, το OHTTP ή το [DAP](https://divviup.org/about/) — αυτά συμβάλλουν στην αποτροπή της σύνδεσης των δεδομένων με εσάς. Σε ορισμένες περιπτώσεις, ενδέχεται να κοινοποιούμε ή να δημοσιεύουμε συγκεντρωτικά και ανωνυμοποιημένα δεδομένα για τη διευκόλυνση της έρευνας ή στο πλαίσιο των νόμιμων επιχειρηματικών σκοπών που περιγράφονται παραπάνω (όπως η κοινοποίηση συγκεντρωτικών πληροφοριών σε διαφημιστικούς συνεργάτες).

### Για επικοινωνία μαζί σας

Ανάλογα με τις ρυθμίσεις σας (και με το αν διαθέτετε λογαριασμό Mozilla ή όχι), ενδέχεται να επικοινωνήσουμε μαζί σας μέσω μηνυμάτων εντός του προϊόντος, να σας στείλουμε μηνύματα (συμπεριλαμβανομένων μηνυμάτων που σχετίζονται με το μάρκετινγκ), να σας ζητήσουμε να συμμετάσχετε σε έρευνες/δημοσκοπήσεις ή να απαντήσουμε σε μηνύματα που αφορούν την υποστήριξη πελατών. Μπορείτε επίσης να επικοινωνήσετε απευθείας μαζί μας, για παράδειγμα για να [αναφέρετε έναν ιστότοπο που δεν λειτουργεί στον Firefox](https://support.mozilla.org/kb/report-breakage-due-blocking#w_what-information-does-mozilla-collect-from-your-report). Όταν επικοινωνείτε μαζί μας μέσω αυτών των μεθόδων, θα χρησιμοποιούμε τις πληροφορίες που κοινοποιείτε μόνο για τον σκοπό για τον οποίο τις παρείχατε. Επίσης, επεξεργαζόμαστε δεδομένα αλληλεπίδρασης που σχετίζονται με αυτές τις επικοινωνίες, για να κατανοήσουμε καλύτερα ποιοι έχουν λάβει τις ανακοινώσεις μας που σχετίζονται με τις υπηρεσίες μας (όπως νέες δυνατότητες, ενημερώσεις ή ειδοποιήσεις ασφαλείας).

Όταν επισκέπτεστε τις σελίδες βοήθειας της Mozilla σχετικά με τον Firefox, η Mozilla συλλέγει τεχνικά δεδομένα και δεδομένα αλληλεπίδρασης σχετικά με τη χρήση των ιστότοπών μας από εσάς, σύμφωνα με τη δήλωση [ιστότοπων, επικοινωνιών και cookie της Mozilla](https://www.mozilla.org/privacy/websites/), ώστε να μπορούμε να κατανοήσουμε τη χρήση των σελίδων υποστήριξης και βοήθειας από εσάς και να τις βελτιώσουμε.

### Για τη συμμόρφωση με την ισχύουσα νομοθεσία και τον εντοπισμό και την πρόληψη επιβλαβών, μη εξουσιοδοτημένων ή παράνομων δραστηριοτήτων

Ενδέχεται επίσης να απαιτείται να επεξεργαστούμε τα δεδομένα σας προσωπικού χαρακτήρα για να συμμορφωθούμε με την ισχύουσα νομοθεσία και με σκοπούς προστασίας, όπως:

* Ανταπόκριση σε νόμιμα αιτήματα και συμμόρφωση με [νομικές διαδικασίες](https://www.mozilla.org/about/policy/transparency/), όπως η ανταπόκριση σε κλητεύσεις, έρευνες ή αιτήματα από κρατικές αρχές. Η Mozilla απαιτεί μια έγκυρη νομική διαδικασία να επιβάλει τη γνωστοποίηση συγκεκριμένων δεδομένων χρήστη σε μια κυβέρνηση.
* Ανταπόκριση σε αιτήματα για την άσκηση δικαιωμάτων απορρήτου, όπως το δικαίωμά σας για πρόσβαση στα δεδομένα σας προσωπικού χαρακτήρα ή τη διαγραφή τους.
* Εντοπισμός, διερεύνηση και αντιμετώπιση πιθανών δόλιων δραστηριοτήτων ή άλλων επιβλαβών δραστηριοτήτων, όπως παράνομες δραστηριότητες, κυβερνοεπιθέσεις ή παραβιάσεις δικαιωμάτων πνευματικής ιδιοκτησίας (συμπεριλαμβανομένης της άσκησης ή της υπεράσπισης νομικών αξιώσεων).
* Εκτέλεση εσωτερικών δραστηριοτήτων συμμόρφωσης και ασφάλειας, όπως έλεγχοι και διαχείριση ασφάλειας της επιχείρησης.

Για την παροχή των υπηρεσιών μας, όπως περιγράφονται παραπάνω, ενδέχεται να κοινοποιούμε δεδομένα προσωπικού χαρακτήρα στους εξής:

|  |  |
| ----- | ----- |
| Συνεργάτες, παρόχους υπηρεσιών, προμηθευτές και εργολάβοι | Για την εκπλήρωση των σκοπών που αναφέρονται παραπάνω, συνεργαζόμαστε με συνεργάτες, παρόχους υπηρεσιών, προμηθευτές και εργολάβους. Έχουμε θεσπίσει συμβατικές διασφαλίσεις, ώστε όσες οντότητες λαμβάνουν δεδομένα προσωπικού χαρακτήρα να υποχρεούνται συμβατικά να χειρίζονται τα δεδομένα σύμφωνα με τις οδηγίες της Mozilla. | Αρχές | Η Mozilla απαιτεί μια έγκυρη νομική διαδικασία να επιβάλει τη γνωστοποίηση συγκεκριμένων δεδομένων χρήστη σε μια κυβέρνηση. Σε αυτές τις περιπτώσεις, ενδέχεται να χρειαστεί να κοινοποιήσουμε τα δεδομένα προσωπικού χαρακτήρα που ορίζονται στην παρούσα Δήλωση στις αρχές επιβολής του νόμου, στις κρατικές αρχές ή σε παρόμοιους φορείς, για τη συμμόρφωση με την ισχύουσα νομοθεσία και τον εντοπισμό και την πρόληψη επιβλαβών, μη εξουσιοδοτημένων ή παράνομων δραστηριοτήτων. |

Μερικές φορές δημοσιοποιούμε πληροφορίες για να βελτιώσουμε τα προϊόντα μας και να προωθήσουμε ένα ανοιχτό διαδίκτυο, αλλά όταν το κάνουμε, θα το πράττουμε σε [μορφή](https://wiki.mozilla.org/Data_Publishing) χωρίς στοιχεία ταυτοποίησης ή/και συγκεντρωτική. |

Ενδέχεται επίσης να χρειαστεί να κοινοποιήσουμε δεδομένα προσωπικού χαρακτήρα στο πλαίσιο μιας εταιρικής συναλλαγής, όπως μια συγχώνευση, μια εξαγορά, μια πώληση περιουσιακών στοιχείων ή μια παρόμοια συναλλαγή. |

## Διεθνείς διαβιβάσεις δεδομένων

Η Mozilla (και οι διακομιστές μας) εδρεύει στις Η.Π.Α. Επειδή είμαστε μια παγκόσμια εταιρεία, προκειμένου να παρέχουμε τις υπηρεσίες που περιγράφονται στην παρούσα Δήλωση απορρήτου, ενδέχεται να παρέχεται πρόσβαση στις πληροφορίες που συλλέγουμε από τοποθεσίες όπου βρίσκονται οι εργαζόμενοί μας, ενώ τα δεδομένα ενδέχεται επίσης να μεταφέρονται σε άλλες δικαιοδοσίες ως αποτέλεσμα της κοινοποίησης δεδομένων στους συνεργάτες μας. Όπου αυτό έχει εφαρμογή, διασφαλίζουμε ότι διαθέτουμε κατάλληλους μηχανισμούς (όπως [τυποποιημένες συμβατικές ρήτρες](https://commission.europa.eu/law/law-topic/data-protection/international-dimension-data-protection/standard-contractual-clauses-scc_en#eu-standard-contractual-clauses) που έχουν εγκριθεί από την Ευρωπαϊκή Επιτροπή και άλλες αρμόδιες αρχές) για την προστασία των δεδομένων σας προσωπικού χαρακτήρα. Μπορείτε να επικοινωνήσετε με τη διεύθυνση [dpo@mozilla.com](mailto:dpo@mozilla.com) για πληροφορίες σχετικά με τις διασφαλίσεις που εφαρμόζονται για τις διεθνείς διαβιβάσεις ή για αντίγραφα των σχετικών τυποποιημένων συμβατικών ρητρών.

## Για ποιο χρονικό διάστημα διατηρούμε τα δεδομένα σας

Διατηρούμε τα δεδομένα σας προσωπικού χαρακτήρα μόνο για όσο χρονικό διάστημα είναι απαραίτητο για την εκπλήρωση των σκοπών που περιγράφονται στην παρούσα Δήλωση απορρήτου. Σε γενικές γραμμές, δεν διατηρούμε δεδομένα προσωπικού χαρακτήρα για περισσότερους από 25 μήνες, αλλά οι πραγματικές περίοδοι διατήρησης ενδέχεται να διαφέρουν ανάλογα με τον τύπο των δεδομένων και τον/τους σκοπό/ούς για τον/τους οποίο/ους συλλέχθηκαν (για παράδειγμα, διατηρούμε την ημερομηνία «πρώτης εμφάνισής» σας για την περίοδο χρήσης του Firefox από εσάς, ώστε να γνωρίζουμε πόσο καιρό είστε χρήστης του Firefox). Οι συγκεκριμένες περίοδοι διατήρησης ενδέχεται επίσης να εξαρτώνται από την ευαισθησία των δεδομένων, το πλαίσιο της συλλογής τους, τις ρυθμίσεις και τις προτιμήσεις σας, καθώς και από τις νομικές ή συμβατικές υποχρεώσεις μας για τη διατήρηση ή τη διαγραφή των δεδομένων σας, όπως για την πρόληψη της απάτης, τη συμμόρφωση με τους κανονισμούς ή τη συνέχεια της παροχής υπηρεσιών. Μόλις λήξει η περίοδος διατήρησης, διαγράφουμε με ασφάλεια τα δεδομένα σας, εκτός αν ο νόμος ορίζει διαφορετικά.

Οι υπηρεσίες μας χρησιμοποιούν επίσης κρυπτογραφημένο αποθηκευτικό χώρο αντιγράφων ασφαλείας ως ένα επιπλέον επίπεδο προστασίας για να διευκολύνουν την ανάκτηση δεδομένων σε περίπτωση πιθανών καταστροφών. Τα δεδομένα σε αυτά τα περιβάλλοντα τίθενται εκτός χρήσης και υποβάλλονται σε επεξεργασία μόνο για σκοπούς επιχειρησιακής συνέχειας. Ενδέχεται επίσης να διατηρούμε δεδομένα για παρατεταμένα χρονικά διαστήματα σε μορφή χωρίς στοιχεία ταυτοποίησης ή συγκεντρωτική.

## Πεδίο εφαρμογής (έκδοση Firefox)

Η παρούσα Δήλωση απορρήτου αφορά την πιο πρόσφατη γενική έκδοση του Firefox που διανέμεται από τη Mozilla. Αν αποκτήσετε τον Firefox από αλλού ή αν εκτελείτε μια παλαιότερη έκδοση, το αντίγραφό σας του Firefox ενδέχεται να περιέχει διαφορετικά χαρακτηριστικά απορρήτου.

Οι εκδόσεις προ κυκλοφορίας του Firefox της Mozilla (οι οποίες διανέμονται μέσω καναλιών όπως τα Nightly, Beta, Developer Edition και TestFlight) είναι πλατφόρμες ανάπτυξης που ενημερώνονται συχνά με πειραματικές δυνατότητες και μελέτες. Εκτός από τη συλλογή δεδομένων που περιγράφεται στην παρούσα Δήλωση απορρήτου, αυτές οι εκδόσεις ενδέχεται, από προεπιλογή, να στέλνουν ορισμένους τύπους δεδομένων σχετικά με τη δραστηριότητα στο Internet και τα σφάλματα στη Mozilla (και, σε ορισμένες περιπτώσεις, στους συνεργάτες μας).
