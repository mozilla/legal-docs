# Firefox 隱私權公告

2026 年 5 月 4 日起生效
{: datetime="2026-05-04" }

## Mozilla 相信，隱私權是健全網路環境不可或缺的基礎。

這也是為什麼我們打造 Firefox 等其餘產品，讓您更能掌握您分享到網路的資訊，以及您分享給我們的資訊。本隱私權公告將說明我們處理哪些資料、如何處理這些資料，以及處理資料的目的。接著，我們將說明您可以如何選擇我們處理您資訊的方式。

## 您的資料如何使用？

### 提供 Firefox 瀏覽器服務

Mozilla 會收集[特定資料](#bookmark-how-we-use-data)（例如技術資料與設定資料），以提供 Firefox 瀏覽器及相關服務的核心功能、區分您的裝置與其他裝置、記住並遵循您的設定，以及提供[新分頁](https://support.mozilla.org/kb/about-new-tab-page)、[PDF 編輯](https://support.mozilla.org/kb/view-pdf-files-firefox-or-choose-another-viewer)、[密碼管理員](https://support.mozilla.org/kb/manage-your-logins-firefox-password-manager)和[全面 Cookie 保護](https://support.mozilla.org/kb/introducing-total-cookie-protection-standard-mode)等預設功能。您還可以調整[控制項、按鈕和工具列](https://support.mozilla.org/kb/customize-firefox-controls-buttons-and-toolbars)，以及透過附加元件[新增功能](https://support.mozilla.org/kb/find-and-install-add-ons-add-features-to-firefox)，進一步自訂 Firefox 使用體驗。

Firefox 的部分功能，例如網頁自動[翻譯](https://support.mozilla.org/kb/website-translation)，以及[為您上傳至 PDF 的圖片提供「替代文字」建議](https://support.mozilla.org/kb/pdf-alt-text)，均透過以下載至您裝置的小型語言模型為基礎的人工智慧（AI）技術運作。這些功能會在本機運作，也就是說，網頁內容、PDF、圖片及分頁網址都會保留在您的裝置上。未經您明確同意，這些資料不會傳送至 Mozilla 的伺服器，也不會用於訓練目的。請注意，Firefox 的其他功能可能整合第三方 AI 模型，詳情請參閱本公告後續說明。進一步了解如何在設定中[控制 AI 功能](https://support.mozilla.org/kb/firefox-ai-controls)與模型等資訊。

如果選擇使用 Smart Window 功能，您對該功能的使用即受[Smart Window 隱私權公告](https://www.mozilla.org/privacy/smart-window/)規範。該公告說明與 Smart Window 相關的資料處理方式。

### 依您的需求調整 Firefox

Firefox 在處理瀏覽記錄、網頁表單資料、網際網路暫存檔和 Cookie等個人資料時，不會將資料傳出您的裝置。這表示上述資料會留在您的裝置上，除非本公告另有說明，否則不會傳送至 Mozilla 的伺服器。如果您選擇允許，系統也可能處理您的精確位置資訊，以便 Google 地圖等網站提供位置相關功能。只有您選擇啟用此權限的網站，才能從您的裝置存取這項資料；資料不會傳送至 Mozilla 的伺服器。

如果您在相容裝置上啟用「搖動以產生摘要」（Shake to Summarize）功能，且裝置使用支援裝置端智慧功能的作業系統，您要求產生的摘要將在裝置本機建立。其他情況下，當您要求產生摘要時，網頁內容會傳送至 Mozilla 伺服器進行處理，再傳回您的裝置；Mozilla 不會儲存這些內容或產生的摘要。進一步了解 [iOS](https://blog.mozilla.org/en/firefox/shake-to-summarize/) 和 [Android](https://support.mozilla.org/kb/summarize-pages-android) 上的「搖動以產生摘要」（Shake to Summarize）功能。

*更多詳細資訊，包括如何調整資料設定：*在您裝置上處理的資料，仍由您自行掌控。您隨時可以[管理瀏覽資料](https://support.mozilla.org/kb/delete-browsing-search-download-history-firefox)和[本機儲存空間設定](https://support.mozilla.org/kb/storage)，或更新[位置存取權限](https://support.mozilla.org/kb/does-firefox-share-my-location-websites)。

### 提供 Firefox VPN

如果您已登入 Mozilla 帳號，您可以啟用 Firefox 功能，以透過代理伺服器（「VPN」）隱藏您的 IP 位址。啟用後，這項功能會透過中介伺服器轉送 Firefox 網路流量，避免您的網路服務供應商取得您連線的伺服器資訊，並向您造訪的網站隱藏您的 IP 位址。這項功能不會代理裝置上其他應用程式的流量，且您無法單憑這項功能以完全匿名的方式瀏覽網站。使用 VPN 可能影響您的瀏覽體驗，例如顯示不適用於您所在地區的內容。

我們透過受託代為營運的代理伺服器提供 VPN 功能。代理伺服器無法存取網頁內容或訊息、密碼等其他敏感資訊，也不會收集您造訪的網站或這些網站內容的相關資料。我們會處理有限的技術資料（例如用戶端版本、連線狀態，以及裝置類型/作業系統）以提供和維護服務，並確保服務的效能與穩定性，也會處理互動資料以了解功能的使用情形，做為改善功能的參考。

### 提供及改善搜尋功能與建議

當您在 Firefox 中輸入搜尋查詢時，Firefox 會提供[搜尋建議](https://support.mozilla.org/kb/search-suggestions-firefox)，讓您更快速、直接地找到所需內容。部分搜尋建議由您的搜尋服務供應商提供（「搜尋建議」）。其他建議則由 Firefox 提供，依據儲存在您本機裝置上的資訊（包括最近使用的搜尋字詞、開啟的分頁及先前造訪的網址），或來自 Mozilla 與 Mozilla 合作夥伴的內容（包括付費贊助商及維基百科等網際網路資源）產生（「Firefox 提供的建議」）。

預設情況下，Firefox 會顯示「搜尋建議」。在您輸入內容時，建議請求（包括您的即時搜尋查詢和技術資料）會直接傳送給搜尋服務供應商，並依該供應商的隱私權公告（[連結如下](#bookmark-search-pns)）進行處理。您隨時可以關閉「搜尋建議」或變更預設搜尋服務供應商，操作方式請參閱此 [Firefox 支援](https://support.mozilla.org/kb/firefox-suggest)頁面。

美國及其他部分地區的使用者也會收到「Firefox 提供的建議」。您可以在瀏覽器設定中完全關閉這些建議，也可以只關閉「Firefox 提供的建議」中的贊助建議。

在美國，Firefox 會在您輸入搜尋查詢時，從 Mozilla 的伺服器擷取建議。我們採用稱為 [OHTTP](https://blog.mozilla.org/en/products/firefox/partnership-ohttp-prio/) 的隱私保護技術，結合加密與代理伺服器，隱藏您的 IP 位址及其他可識別身分的資訊。預設情況下，您的即時搜尋查詢、技術資料、互動資料及依 IP 位址推得的位置資料，會先經過 OHTTP 代理伺服器，再傳送至 Mozilla。這有助於防止任何人（包括 Mozilla）將特定搜尋查詢與您連結，或將該查詢與您瀏覽活動的其他無關資訊合併。Mozilla 處理這些資料的目的，是為了提供相關建議、了解建議對您的實用程度，以及改善服務。在某些情況下，Mozilla 的合作夥伴會收到去識別化的搜尋及互動資料，以提供相關建議，並衡量使用者與建議內容的互動情形。

部分使用者（包括美國境外某些地區的使用者，以及在設定中取消選取「輸入時從 Mozilla 擷取建議」的美國使用者）使用「Firefox 提供的建議」功能時，將改為收到在本機處理的結果。對這些使用者而言，Firefox 會利用儲存在裝置上的資訊，在本機提供建議。系統會透過 OHTTP 將與特定查詢關鍵字相關的去識別化點擊及互動資料（不包含您的搜尋查詢內容）傳送給 Mozilla，以隱藏您的 IP 位址及其他可識別身分的資訊。對於贊助搜尋建議，我們的合作夥伴可能會收到彙總資訊，了解其提供的哪些建議曾經顯示及獲得點擊，但不會得知哪些使用者看過這些建議，或是哪些關鍵字觸發了這些建議的顯示。（如果您所在的地區不提供「Firefox 提供的建議」，您只會收到「搜尋建議」。）

### 在 Firefox 新分頁提供相關內容與廣告

Firefox 會在新分頁顯示內容與廣告，以支持 Firefox 的開發。您隨時可以在瀏覽器設定中關閉這些內容與廣告。

我們使用技術資料、語言偏好設定及依 IP 位址推得的位置資訊，以適當的格式（例如行動版或桌面版）、語言及相關地區提供這些內容。Mozilla 會收集技術與互動資料，例如新分頁內容或廣告的位置、大小、瀏覽次數及點選次數，以了解使用者如何與我們的內容互動，並提供個人化的後續內容（包括贊助內容）。我們可能以彙總及/或去識別化的形式，與廣告合作夥伴分享這些資料。

在部分地區，我們會使用這些資料建立模型，並依共同屬性將使用者分組。這些分組有助於我們了解使用者如何與內容互動，以及提供個人化的後續內容，包括贊助內容。我們使用裝置端處理技術與 OHTTP，避免向 Mozilla 揭露任何特定使用者的屬性。[了解更多資訊](https://support.mozilla.org/kb/firefox-new-tab-personalization)。

我們也與廣告服務供應商合作，透過程式化技術提供相關贊助內容。為此，我們可能分享有限且無法識別個人身分的資訊，例如裝置類型、依 IP 位址推得的位置資訊，以及已瀏覽內容的類別，以協助判斷應顯示哪些廣告。我們不會分享任何可識別您身分的資訊。您隨時可以在新分頁設定中關閉贊助內容。

在某些情況下，當新分頁啟用廣告時，系統也可能在您的裝置上於本機處理其他瀏覽和互動資料（包括與我們廣告客戶的互動），以衡量這些廣告的成效；[捷徑](https://support.mozilla.org/kb/about-new-tab-page#w_shortcuts)功能也會在您的裝置上使用本機瀏覽資料挑選最常用的捷徑，其中部分可能是贊助捷徑。任何此類資料都只會透過我們的隱私保護技術，以彙總及/或去識別化形式與 Mozilla 及/或廣告合作夥伴分享。

當使用者透過 Firefox 中的廣告或連結造訪第三方網站時，該網站可能使用 Cookie 及所有網站均可使用的其他網頁 API 收集資料，並受該網站的隱私權及/或 Cookie 公告規範。

您可以在瀏覽器設定中，關閉或自訂任何上述新分頁功能及其相關資料處理方式（[桌面版](https://support.mozilla.org/kb/customize-your-new-tab-page)、[Android](https://support.mozilla.org/kb/customize-firefox-home-screen)、[iOS](https://support.mozilla.org/kb/customize-firefox-home-ios)）。您也可以[停用贊助內容](https://support.mozilla.org/kb/sponsor-privacy)，同時繼續使用其他功能。

### 提供 Mozilla 帳號

如果您註冊 Mozilla 帳號，除了本公告所述的資料外，我們還會依照[Mozilla 帳號隱私權公告](https://www.mozilla.org/privacy/mozilla-accounts/)處理其他資訊，例如帳號詳細資料、聯絡資訊及同步資料。

### 提供 AI 聊天機器人

您可以選擇使用第三方 AI 聊天機器人，協助摘要閱讀內容、寫作及發想創意等工作，但須遵守該服務供應商的[使用條款與隱私權公告](https://support.mozilla.org/kb/ai-chatbot#w_learn-about-chatbot-providers)。

如果您選擇在側邊欄及/或透過捷徑啟用聊天機器人，Mozilla 無法存取您的對話，或您輸入所選聊天機器人的原始內容。我們會收集這項功能使用情形的技術及互動資料，以協助改善 Firefox，例如各第三方聊天機器人服務供應商的選用頻率、建議提示詞的使用頻率，以及所選文字的長度。

*更多詳細資訊，包括如何調整資料設定：*進一步了解如何在 Firefox 中[管理或移除](https://support.mozilla.org/kb/ai-chatbot) AI 聊天機器人。

### 提供及啟用附加元件（addons.mozilla.org）

您可以透過 [addons.mozilla.org](https://addons.mozilla.org)（「AMO」）或附加元件管理員（可由工具列中的 Firefox 選單按鈕存取）安裝附加元件。我們會處理您在附加元件管理員中輸入的搜尋查詢，以便向您推薦附加元件。如果您選擇安裝任何附加元件，Firefox 會處理技術資料、依 IP 位址推得的位置資料與設定資料，並定期連線至 Mozilla 的伺服器，以安裝附加元件並套用正確的更新。我們也會收集附加元件使用情形的技術及互動資料，以協助改善 Firefox。

當您造訪 [AMO 網站](https://addons.mozilla.org/firefox/)時，Mozilla 會依照 [Mozilla 網站、通訊及 Cookie](https://www.mozilla.org/privacy/websites/) 公告，收集您使用網站的技術及互動資料。

*更多詳細資訊，包括如何調整資料設定：*了解[如何移除或啟用附加元件](https://support.mozilla.org/kb/disable-or-remove-add-ons)。您也可以查閱[隱私權公告](https://www.mozilla.org/privacy/websites/)，了解[附加元件網站](https://addons.mozilla.org/firefox/)的隱私權實務。

### 維護及改善功能、效能與穩定性

Mozilla 會在 Firefox 中進行[研究](https://support.mozilla.org/kb/shield)，並透過 Firefox Labs 提供特定[實驗性功能](https://support.mozilla.org/kb/firefox-labs-explore-experimental-features-firefox)，以便在向所有 Firefox 使用者開放或納入 Firefox 核心功能前，測試各種功能與構想。這有助於我們更充分掌握使用者的期望與需求，並據以做出決策。這類研究會使用技術資料、系統效能資料、依 IP 位址推得的位置資料、設定資料及互動資料。

我們也需要處理資料，以維持 Firefox 正常運作、改善功能與效能，以及找出、排除和診斷問題。為此，我們會使用技術資料、依 IP 位址推得的位置資料及設定資料，以及互動資料和系統效能資料（例如開啟的分頁數、記憶體使用量或更新等自動化程序的結果）。在極少數情況下，所需資訊也包含有限的瀏覽資料（例如用於監測網頁載入效能的頂層網域註記），這些資料將透過 OHTTP 傳輸；這有助於避免 Mozilla 將您或您的裝置與為此目的收集的資料連結。

在桌面版和 Android 版中，如果 Firefox 遇到非預期問題，[Mozilla 當機回報工具](https://support.mozilla.org/kb/mozillacrashreporter)也會詢問您是否願意向我們傳送其他資訊，其中可能包含當機時開啟的網站及其他瀏覽資料。在桌面版和 Android 版中，如果您選擇自動傳送當機報告，我們便會收集上述資訊，而不會每次都詢問您；在 iOS 版中，當機報告包含的資訊較少，且預設會自動傳送給我們。您隨時可以變更設定。

*更多詳細資訊，包括如何調整資料設定：*您可以[進一步了解](https://support.mozilla.org/kb/shield)自己參與的研究，並隨時退出全部或特定研究，也可以透過 [Firefox Labs](https://support.mozilla.org/kb/firefox-labs-explore-experimental-features-firefox) 選擇加入實驗性功能。您也可以[進一步了解](https://support.mozilla.org/kb/technical-and-interaction-data)我們處理的技術與互動資料，包括如何關閉相關資料收集。

### 提升安全性

使用最新版本的 Firefox 有助於防範安全漏洞，因此桌面版 Firefox 會定期連線至 Mozilla 的伺服器（或您安裝 Firefox 時使用的其他服務），檢查軟體更新；Android 版和 iOS 版 Firefox 的更新，則分別由 Google Play 商店及 Apple App Store 管理。

我們也會處理技術資料及設定資料，以防範惡意附加元件。
除了這些標準程序外，我們也使用[Google 安全瀏覽服務](https://support.mozilla.org/kb/how-does-phishing-and-malware-protection-work)，防範惡意下載與網路釣魚攻擊，並透過[憑證授權機構](https://support.mozilla.org/kb/secure-website-certificate)驗證網頁及技術資料。為了提升所有網際網路使用者的隱私權與安全性，我們會透過 OHTTP 收集技術資料，以深入了解、預防和防範指紋辨識追蹤。

[部份使用者的 Firefox](https://support.mozilla.org/kb/firefox-dns-over-https) 會向解析程式服務傳送 DNS 要求，該服務已同意 Mozilla 的[解析程式嚴格隱私權標準](https://wiki.mozilla.org/Security/DOH-resolver-policy)。這樣做能進一步防止隱私內容洩漏至當地網路，也能防護特定的 DNS 安全性攻擊。該服務在 24 小時內便會刪除 DNS 要求的系統記錄，並只會將該記錄用來進行 DNS 解析。[進一步了解](https://support.mozilla.org/kb/firefox-dns-over-https#w_switching-providers)透過 HTTPS 傳送 DNS 的相關資訊。

*更多詳細資訊，包括如何調整資料設定：*[升級與附加元件封鎖清單](https://support.mozilla.org/kb/how-stop-firefox-making-automatic-connections)、[Google 安全瀏覽服務](https://support.mozilla.org/kb/how-does-phishing-and-malware-protection-work)、[OHTTP](https://blog.mozilla.org/en/products/firefox/partnership-ohttp-prio/)。

### 了解 Firefox 的使用情形

我們會處理[資料](#bookmark-understand-usage)，以深入了解您使用服務的情形，例如 Firefox 的使用量、語言偏好、使用搜尋工具或與搜尋建議互動的頻率、網頁載入速度，以及您看到的廣告或[驗證碼](https://en.wikipedia.org/wiki/CAPTCHA)（CAPTCHA）數量。這讓我們能衡量使用者存取及使用服務的方式，進而改善業務及 Firefox 的功能。

*更多詳細資訊，包括如何調整資料設定：*您隨時可以更新[桌面版](https://support.mozilla.org/kb/share-data-mozilla-help-improve-firefox)及[行動版](https://support.mozilla.org/kb/mobile-manage-firefox-data-collection-and-privacy)的資料收集設定。請注意，即使取消選取「允許 Firefox 傳送技術及互動資料至 Mozilla」，也不會影響[每日使用情形 Ping](https://support.mozilla.org/kb/usage-ping-settings)。每日使用情形 Ping 只會向我們提供去識別化資訊，表明有使用者正在使用 Firefox；這項資訊不會與您的其他資料連結，而且您可以在設定中選擇停用。

### 行銷宣傳我們的服務

在取得您的允許後，Firefox 會向 Mozilla 傳送將您導向下載頁面的網站網域或特定廣告活動（如有）的資料，以協助我們了解及改善行銷成效。Firefox 也會與行銷合作夥伴分享資訊，以衡量及改善這些行銷活動。實際分享的資訊會因您發現 Firefox 的方式及使用的作業系統而異，但通常包括您如何被導向我們的下載頁面，以及您是否經常使用 Firefox。如果 Firefox 已預先安裝在您的裝置上，技術與互動資料（您的裝置類型及是否使用 Firefox）將傳送給我們的行銷合作夥伴，並與 Mozilla 分享。

*更多詳細資訊，包括如何調整資料設定：*進一步了解收集及分享哪些[行銷活動成效衡量資料](https://support.mozilla.org/kb/desktop-attribution-privacy)，以及如何選擇退出。Firefox 不會與行銷技術合作夥伴分享您的瀏覽記錄、搜尋查詢或儲存的密碼等資訊。Mozilla 只會收集衡量及改善行銷活動所必需的資料。

### 對資料進行假名化、去識別化、彙總或匿名化處理

在執行上述活動（例如了解 Firefox 的使用情形及衡量行銷成效）時，我們可能產生經假名化、去識別化、彙總或匿名化處理的資料。我們會依具體情況採用適當技術，包括移除識別碼、OHTTP 或 [DAP](https://divviup.org/about/)，以協助防止資料與您產生連結。在某些情況下，我們可能分享或公開彙總及匿名化資料，以促進研究，或用於上述合法商業目的（例如與廣告合作夥伴分享彙總分析結果）。

### 與您聯絡

依您的設定（以及您是否擁有 Mozilla 帳號），我們可能透過產品內訊息與您聯絡、向您傳送通知（包括行銷相關通知）、邀請您參與研究/問卷調查，或回覆客戶支援相關來訊。您也可以主動聯絡我們，例如透過 Firefox [回報網站無法正常運作](https://support.mozilla.org/kb/report-breakage-due-blocking#w_what-information-does-mozilla-collect-from-your-report)的問題。當您透過上述方式與我們聯絡時，我們只會將您分享的資訊用於您提供資訊時所指定的目的。我們也會處理與這些通訊相關的互動資料，以深入了解哪些人收到了我們的服務相關公告（例如新功能、更新或安全性警示）。

當您因使用 Firefox 而造訪 Mozilla 的說明頁面時，Mozilla 會依照[Mozilla 網站、通訊及 Cookie](https://www.mozilla.org/privacy/websites/) 公告，收集您使用我們網站的技術及互動資料，以了解使用者如何使用支援與說明頁面，並加以改善。
